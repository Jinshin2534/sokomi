# 底見 (sokomi) — 靴底すり減り推定 設計書

日付: 2026-10-12

## 目的

新品時に撮った靴底の写真を基準にして、今の靴底写真と比べ、
**部位ごとのすり減りマップ**と**全体のすり減り%**を出す。

## 方針

- 推定はブラウザ内の画像解析だけで行う（サーバー・APIキー不要）。
- すり減ると溝の縁や模様が消える＝局所的なエッジの強さ（以下「模様の強さ」）が減る、を測る。
- 根拠のない数字は出さない。判定できないマスは「判定不能」と表示する。

## スタック

- Vite + 素のJS、pnpm、Vitest。開発ポート 5730。
- 写真と靴データは IndexedDB に保存する（写真は縮小 JPEG Blob で保存）。

## 画面と流れ

1. **靴一覧**: 登録済みの靴カード（名前・基準写真サムネ・最新のすり減り%）。「＋靴を登録」。
2. **基準登録**: 名前入力 → 新品の靴底を撮影/選択（`<input type=file accept=image/*>`。capture は付けない＝スマホでカメラとアルバムの両方を選べる）→ 4点タップ → 保存。
3. **チェック**: 靴を選ぶ → 今の靴底を撮影/選択 → 4点タップ → 解析 → 結果。
4. **結果**: ヒートマップ（正規化した靴底の上に重ねる）、6部位の平均、全体%、信頼度、撮り直しの勧告。チェック結果は靴ごとに履歴として保存し、一覧に最新値を出す。

撮影ガイド（毎回表示）: 真上から・無地で靴底と色の違う背景・基準写真と同じ照明・靴底全体が入る。

## 4点タップ

順番固定で案内する: ①つま先の先端 ②かかとの先端 ③内側(親指側)の一番広い所 ④外側(小指側)の一番広い所。
タップ後に点はドラッグで微調整できる。左右どちらの靴でも、内側/外側で指定するので向きの区別は不要。
4点そろうと、解析が想定する靴底テンプレートの輪郭を写真の上に白線(暗い下敷き線つき)で描く。白線が靴底のふちに大体そろうよう点を動かしてもらう。点が不正で輪郭を描けないときは「点の位置がおかしいようです」と出す。
写真の canvas は object-fit を使わず、要素の箱が写真と同じ縦横比になるようにする(余白があるとタップ位置がずれるため)。

## 解析パイプライン（src/lib、すべて純粋関数）

入力は `{width, height, data: Uint8ClampedArray(RGBA)}` 形式の画像（ImageData 相当）。

1. **homography.js**: 4点 → 正規化座標への射影変換。
   正規化座標は u(横 0=内側〜1=外側), v(縦 0=つま先〜1=かかと)。
   対応: つま先=(0.5,0) かかと=(0.5,1) 内側最大幅=(0,0.35) 外側最大幅=(1,0.35)。
   4点がほぼ一直線など退化している場合はエラーを返す（UIで「点を打ち直して」）。
   `pointsOrientation(points)` は内側の点が「つま先→かかと」の線のどちら側か(±1)。新品時と今とで符号が違えば内側と外側を逆に打っている。
2. **warp.js**: 写真を正規化座標の固定解像度グレースケール画像（W=120, H=300）に双線形補間で再標本化。輝度は 0.299R+0.587G+0.114B。
3. **mask.js の maskOutsideSole**: 正規化の前に、画素中心がテンプレート(縮めない輪郭)の外の画素を NaN にする。背景を局所平均の窓に入れず、靴底の縁の輪郭エッジを模様の入力から外すため(模様なしの合成靴底で、マスに漏れ込む値が 0.24→0.005)。信頼度と結果画面の下地にはマスク前の画像を使う。
   **normalize.js**: 照明正規化。広い窓（半径15px）の局所平均で割る（下限8）。明るさ・露出のゲイン差とゆるい陰影を消す。
   局所標準偏差で割る方式は採らない: すり減って平らなマスのノイズを増幅し、すり減りの信号そのものを消してしまうため。
4. **texture.js**: Sobel 勾配の大きさ → マス（12×30 グリッド、1マス=10×10px）ごとの平均＝模様の強さ。
5. **mask.js**: 靴底の形のマスク。正規化座標上の靴底テンプレート（つま先・最大幅・土踏まずのくびれ・かかとを通る滑らかな輪郭、u,v の関数）で外側を除外。
   マスの4隅すべてが「テンプレートを0.9倍に縮めた輪郭」の内側にあるマスだけ使う（靴底の縁と背景の境目は強いエッジだが、すり減らないので混ぜると値が薄まる）。さらに**基準画像で模様の強さがしきい値未満のマスは「判定不能」**（平らな部分は比較できない）。しきい値 = max(0.3, 靴底内の基準の中央値×0.25)。0.3 は、実物の靴底がテンプレートより細く輪郭がマスクの内側に入る場合の漏れ込み(実測 幅0.92倍で0.11)に約3倍の余裕を取った値。
6. **wear.js**: マスごとのすり減り度 = 1 − 今/基準（マスでは切らない。負や1超えもありうる）。判定不能マスは null。マスごとに 0〜1 に切ると ± の揺れが + 側にだけ残って平均が上ずるため、部位・全体で平均してから 0〜1 に収める。
7. **regions.js**: 6部位に集計。部位の境界は v と u で定義:
   - つま先: v<0.18
   - 母趾球: 0.18≤v<0.42 かつ u<0.5
   - 小趾側: 0.18≤v<0.42 かつ u≥0.5
   - 土踏まず: 0.42≤v<0.68
   - かかと内: v≥0.68 かつ u<0.5
   - かかと外: v≥0.68 かつ u≥0.5
   部位ごとに平均と判定可能マスの割合を出す。判定可能マスが部位の 30% 未満なら部位の値は null（「判定不能」）。
   全体% = 判定可能マスの平均（各マスは同面積なので単純平均）。判定可能マスが全体の 25% 未満なら全体も null。部位・全体の平均は最後に 0〜1 に収める。
8. **quality.js**: 信頼度。正規化前・マスク前の2画像について測る。
   - 明るさ: 靴底の内側(0.9倍に縮めた輪郭)の平均輝度の比。<0.5 / >2 で低、<0.7 / >1.4 で中。
   - ピント: 平均|ラプラシアン| ÷ 平均|勾配| を、**靴底の縁の帯**(テンプレート半幅の 0.85〜1.15倍)で測った比。縁はすり減らないので、すり減りに左右されずピントだけを映す。<0.6 で低、<0.8 で中。
     合成靴底での実測比: 同じ写真 1.00 / すり減り 1.00 / 全部すり減り 1.06 / 半分の解像度 0.89 / ぼかし(半径1×1) 0.83・(半径2×1) 0.63・(半径4×3) 0.35。
   - 白飛び・黒つぶれ: 靴底の内側で 250以上か5以下の画素の割合が 2割超なら中。新品時・今の両方を見て、どちらの写真か理由に書く。
   理由を文で返す（「今の写真が新品時よりかなり暗いです」「ピントが甘いか、手ブレしています」など）。値は 高/中/低。
9. **analyze.js**: 上記をつないだ入口 `analyze(baseImage, basePoints, nowImage, nowPoints) → {cells, regions, overall, quality}`。点が不正なら Error('degenerate')、内側と外側を新品時と逆に打っていたら Error('mirrored')（UIで「内側と外側の点が新品時と逆になっています…」）。

## 表示

- ヒートマップ: 0%=緑 → 50%=黄 → 100%=赤、判定不能=斜線グレー。今の写真を正規化したものの上に半透明で重ねる。
- 部位カード6枚＋全体%の大きい数字。どれも「判定不能」はそう書く。
- 見方の注記: 「模様のくっきり具合の減り方から推定した値で、溝の深さを測ったものではありません」。

## 構成

```
src/lib/      純粋関数（上記）＋ storage.js（IndexedDB 薄いラッパ、テスト対象外）
src/app.js    画面の配線、window.__app を公開（ヘッドレス検証用: 画像と点を直接渡して解析できる）
src/ui/       画面ごとの描画（list / register / check / result / pointPicker）
```

## テスト（Vitest）

- homography: 既知の4点で往復一致、退化で例外。
- 合成画像: 縞模様の靴底を描いた基準画像と、一部領域の縞を消した（または振幅を半分にした）今画像を作り、
  消した部位のすり減り度が高く（>0.8／≈0.5）、触っていない部位が低い（<0.1）ことを確認。
- 明るさ違い: 今画像を全体に暗く（×0.6）しても触っていない部位のすり減りが低いまま（正規化の確認）。
- 回転・拡大して撮った今画像（4点も同じ変換）で結果がほぼ同じ。
- 判定不能: 模様のない基準領域は null、閾値割合未満で部位・全体が null。
- quality: 暗い/ぼけた画像で「低」と理由が返る。すり減っていてもピントの理由は出ない。1.6倍明るいと「少し明るい」で中。白飛びはどちらの写真か分けて返す。
- 実物の靴底がテンプレートと違う形（幅0.92倍・1.08倍・土踏まず非対称）＋背景の明るさが新品時と違う（40⇄200）でも、触っていない部位は 0.1 未満。
- 内側と外側を逆に打つと mirrored。

## 入れないもの

買い替え時期の予測、左右比較、アカウント・クラウド同期、自動の輪郭検出。
